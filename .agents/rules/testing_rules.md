# قواعد الاختبار والتشغيل (Testing & Server Execution Rules)

1. **حظر تشغيل الخادم من قبل المساعد البرمجي (Do NOT start the server)**:
   - يمنع على المساعد الذكي تشغيل خادم التطوير (`npm run dev` أو `npm run desktop:dev` أو أي عملية سيرفر مماثلة) بشكل تلقائي أو في الخلفية إطلاقاً.
   
2. **المستخدم هو المسؤول عن الاختبار (User-driven Testing)**:
   - المستخدم هو دائماً من يقوم بتشغيل السيرفر واختبار المشروع والتأكد من الواجهات والوظائف بعد كل تعديل أو تطوير.
   - يكتفي المساعد بالتحقق البرمجي فقط (مثل التحقق من البناء `npm run build` للتحقق من عدم وجود أخطاء TypeScript).
